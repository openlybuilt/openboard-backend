# Swimlane process

- Give each actor or system a named horizontal frame. Put each task in the lane of the actor that performs it.
- Move the main process left to right. Cross lane boundaries only for a real handoff; label the handoff if its meaning is not clear.
- Keep decisions near the actor who makes them. Put return loops and exception paths in open corridors between or outside lanes.
- Increase lane height or canvas width when arrows, labels, and tasks compete for the same space.
- Check that actor ownership, decision outcomes, cross-lane handoffs, and return paths match the source.
